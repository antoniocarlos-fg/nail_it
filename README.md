# Nail It!

Um aplicativo mobile para gerenciamento de uma coleção pessoal de esmaltes, desenvolvido com **Flutter** e **Dart**.

> 🚧 **Em desenvolvimento** — O projeto está atualmente em desenvolvimento, com foco inicial na construção da interface, navegação e gerenciamento dos dados. *The application is being developed as part of an academic mobile development project.*

## Sobre

O **Nail It!** é um aplicativo voltado para pessoas que desejam organizar e acompanhar sua coleção pessoal de esmaltes.

A proposta é permitir que o usuário visualize os produtos que possui, acompanhe seu estado de uso, pesquise novos esmaltes e mantenha uma lista de desejos.

*The project focuses on creating a simple and intuitive experience for managing a personal nail polish collection.*

## Funcionalidades

* Login e cadastro de usuários
* Recuperação de senha
* Visualização da coleção de esmaltes
* Pesquisa de esmaltes
* Gerenciamento do estoque pessoal
* Controle do estado de utilização dos produtos
* Wishlist
* Perfil de usuário
* Tela sobre o aplicativo

Os estados de utilização planejados para os esmaltes são:

* **Novo**
* **Usando**
* **Acabando**

A pesquisa de produtos deverá utilizar a **API do Mercado Livre**, permitindo encontrar esmaltes e adicioná-los à coleção ou à wishlist.

## Tecnologias

* [Flutter](https://flutter.dev/) — Framework para desenvolvimento multiplataforma
* Dart — Linguagem de programação
* Provider / ChangeNotifier — Gerenciamento de estado
* Material Design — Diretrizes visuais e componentes da interface

## Desenvolvimento

Clone o repositório e instale as dependências:

```bash
git clone https://github.com/antoniocarlos-fg/nail_it.git
cd nail_it
flutter pub get
```

Execute o aplicativo em modo de desenvolvimento:

```bash
flutter run
```
